# 奶龙投稿助手

作者用邮箱批量投稿的桌面管理工具：管理收稿编辑与文稿，多邮箱轮投向编辑投稿，并自动监控收件箱、按关键词判定回信（过稿/退稿/需修改）。纯本地应用，数据只保存在你自己电脑上。

- 技术栈：Python 3.10 + PySide6（Qt 原生控件 + QSS 卡片风，5 套主题色）
- 存储：SQLite（标准库），无网络账号体系
- 邮件：SMTP 发信（支持 docx 附件、发件人显示名）、IMAP 只读取信

## 开发运行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe main.py
```

自检（无头，不弹窗，异常返回非 0）：

```bash
QT_QPA_PLATFORM=offscreen NAILONG_SMOKE=1 .venv/Scripts/python.exe main.py   # 输出 SMOKE_OK
```

冒烟测试：`scripts/smoke_phase1.py`、`smoke_phase2.py`、`smoke_phase3.py`（offscreen + 临时数据目录）。

## 打包 exe

- 便携版：双击 `build_exe.bat`（PyInstaller `--onefile --noconsole`），产物为 `dist\奶龙投稿助手.exe`。
- **安装版**：双击 `build_installer.bat`（需先 `winget install JRSoftware.InnoSetup`），产物为 `dist\奶龙投稿助手-<版本>-windows-setup.exe`。安装/卸载不影响激活（激活数据在数据目录，见下）。

## 数据目录

按系统区分（设置页底部可见实际路径）：

- Windows：`%APPDATA%\NailongPost\`
- macOS：`~/Library/Application Support/NailongPost/`
- Linux：`$XDG_DATA_HOME/NailongPost/`（未设置时为 `~/.local/share/NailongPost/`）

- `nailong.db` — 编辑、文稿、投递记录、回信、设置
- `files\` — 文稿文件副本（投稿附件从这里取）

测试时可用环境变量 `NAILONG_DATA_DIR` 覆盖数据目录。

## 系统要求与多平台打包

- **Windows 10 / 11 64 位**（不支持 Win7：Qt6 与 Python 3.9+ 均已放弃 Win7）
- **macOS 11+**：CI 产物为 `.dmg` 安装包（打开后把 App 拖进 Applications）。未做苹果签名，首次打开请「右键 → 打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/奶龙投稿助手.app`
- **Linux**（Debian/Ubuntu）：CI 产物为 `.deb` 安装包，`sudo apt install ./奶龙投稿助手-*-linux-amd64.deb` 即可（自动带出 Qt 运行依赖），安装后应用菜单出现「奶龙投稿助手」；卸载：`sudo apt remove nailong-post`

### Windows 打开时报错「DLL load failed / QtWidgets / 找不到指定的模块」

这是 PySide6（Qt）依赖的系统运行库缺失或 exe 打包异常，按顺序处理：

1. **安装 Visual C++ 运行库（最常见）**  
   下载并安装 **Microsoft Visual C++ 2015–2022 可再发行组件包 (x64)**：  
   https://aka.ms/vs/17/release/vc_redist.x64.exe  
   装完后重启电脑，再双击 exe。
2. 确认是 **64 位 Windows 10/11**，不要把程序放进仅同步的网盘目录（可先复制到桌面再试）。
3. 若仍失败：用本仓库重新打包的 exe（已关闭 UPX 压缩，避免压坏 Qt DLL），或从最新 Release / Actions 产物下载。

macOS / Linux 安装包由 GitHub Actions 自动构建（PyInstaller 不支持跨平台编译）：推送到 main 即触发三平台构建，产物在 Actions 页面下载；打 `v*` 标签会自动创建 Release 并附三平台安装包。

本地在对应系统手动打包亦可：

```bash
pip install -r requirements.txt pyinstaller
pyinstaller 奶龙投稿助手.spec   # 产物在 dist/
```

## 使用流程

1. **设置 → 发信邮箱**：默认 6 个投稿邮箱槽位，不够用可点「＋ 添加邮箱」追加；配置后测试连通；**投稿信模板**可按需自定义（占位符 {编辑称呼} {作品名} {字数} {分类}）
2. **编辑列表**：新增或 CSV 导入收稿编辑（名称/平台/邮箱/题材/稿费），可收藏、关小黑屋
3. **文稿库**：新建文稿或上传 txt/docx（自动统计字数）
4. **投稿方案**：选文稿 → 生成投稿信 → 勾选编辑 → 开始投稿（多邮箱轮转、逐封发送、进度日志）
5. **回信中心**：立即收信或等后台自动收信，自动判定过稿/退稿/需修改并回写投递记录
6. **工作台**：查看统计、新手指引与近期动态

## 注意事项

- 邮箱填的是**授权码而非登录密码**（QQ/163 等在邮箱设置里开启 SMTP/IMAP 后生成）
- **一稿一投保护**（默认开）：同一文稿同一编辑在收到回复前不会重复投递；同平台重复编辑与小黑屋会自动跳过；每个邮箱有单日投递上限
- 收信对收件箱**只读**：不删邮件、不改已读状态，只拉取编辑列表内发件人的来信
- 回信判定是本地关键词规则，"需修改 > 过稿 > 退稿 > 其他"，判定为"其他"不会改变投递状态

## 功能补充

- **内置编辑库**：首次启动自动导入 2481 位编辑（含各平台收稿邮箱/收稿方向/收稿状态，来自公开征稿信息）；已停止收稿的默认进小黑屋（不投但可见，可手动解除）
- **云端同步**：编辑列表页点击「同步最新编辑」按钮，从项目固定的 GitHub 公开数据源下载最新编辑数据（含收稿方向/状态），自动合并更新本地列表（按邮箱匹配，保留收藏/小黑屋/退信标记）
- **退信自动标记**：收信时识别退信通知（mailer-daemon/退信类主题），自动把被退回的编辑邮箱标记"失效"（红色），投稿时自动跳过，编辑列表可一键"恢复有效"
- **催稿提醒**：投递策略可设提醒天数（默认 30 天），超期未回复的投稿会在工作台提醒，投递记录里发信时间标橙
- **投稿信模板**：设置页可自定义主题/正文模板（占位符 {编辑称呼} {作品名} {字数} {分类}），可一键恢复默认
- **数据统计**：工作台底部展示各平台投递/回复/过稿/过稿率与平均回复时长（仅统计本机软件内的投递记录）
- **数据备份**：设置页可导出/导入整库备份（导入需重启生效），也可清空全部业务数据（保留设置）
- **定时投稿**：投稿页可预约发送时间，软件每 30 秒检查一次，到点自动按既有规则（邮箱轮转、单日上限）发出
- **稿费记录**：稿子卖出后在"稿费记录"页登记平台/编辑/金额/打款月份，文稿库对应文稿显示"已售"徽章，工作台动态也会显示售出事件
